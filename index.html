CREATOR-STUDIONEW · NOV 2026PUBLISHING · PRIVATE REPO

Creator Studio

One upload, seven platforms, no AI in the loop

A local-first publishing app for two creators and three brands. Upload a video once, write your own text, pick accounts, review exactly what each destination will receive, and publish to YouTube, Instagram, Facebook, Threads, LinkedIn, X and Pinterest. Nothing in it generates or rewrites text.

The interesting part is reliability. Every destination is its own job, with exponential backoff on network and rate-limit errors, resumable chunked YouTube uploads and duplicate refusal. If the connection drops at the moment a post is created, the outcome is marked uncertain and stops for a human check, so nothing is ever posted twice.

VIDEO-ENGINENEW · NOV 2026AUTOMATION · PRIVATE REPO

Story Video Engine

Roblox-style vertical shorts, generated entirely by code

A Blender-driven pipeline that turns a video idea into an upload-ready 1080×1920 short, with no manual animation and no video editor. A script and a shots file go in; a character generator, 54 props and a library of sets build the scene.

One command runs every stage: shots validated against the engine's vocabulary, ElevenLabs voice-over with an Edge TTS fallback, QA contact sheets, the render, then a Blender sequencer edit for voice, music, sound effects, captions and transitions. One rule I held to: never patch a single episode by hacking the engine, so it stays general.

Health & Skincare Assistant

LoRA fine-tune of Qwen3.5-0.8B that runs on a laptop

A very small model for skincare, nutrition and general wellness questions such as weight loss and weight gain. The goal was a 0.8B model that stays useful at low memory, so the training data was generated as JSONL and filtered to leave out examples the base model already answers well.

Trained by me with Unsloth, merged to 16-bit weights, then exported as a Q4_K_M GGUF that runs through Ollama on consumer hardware.

LOCAL-CODE-AGENTAGENT · PUBLIC REPO

Offline Coding Agent

Built for a 0.8B model on a 2 GB GPU

A coding agent for small local models, with no internet and no dependencies beyond the Python standard library. The harness decides the next step and the model only does tiny, well-defined jobs: write these tests, write this code, fix this failing output.

Each step follows a fixed loop of tests first, implement, run the tests, then commit, with bounded retries, a loop guard, and rollback on any failure. It was built through 20+ reviewed pull requests, with full prompt and reply transcripts for debugging and a model benchmarking command. It has built working apps step by step, including an HRMS, a task manager and a restaurant event-management backend.
