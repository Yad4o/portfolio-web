LORAMODEL DEVELOPMENT

Health & Skincare Assistant

LoRA fine-tune of Qwen3.5-0.8B that runs on a laptop

A very small model for skincare, nutrition and general wellness questions such as weight loss and weight gain. The goal was a 0.8B model that stays useful at low memory, so the training data was generated as JSONL and filtered to leave out examples the base model already answers well.

Trained by me with Unsloth, merged to 16-bit weights, then exported as a Q4_K_M GGUF that runs through Ollama on consumer hardware.

04
LOCAL-CODE-AGENTAGENT · PRIVATE REPO

Offline Coding Agent

Built for a 0.8B model on a 2 GB GPU

A coding agent for small local models, with no internet and no dependencies beyond the Python standard library. The harness decides the next step and the model only does tiny, well-defined jobs: write these tests, write this code, fix this failing output.

Each step follows a fixed loop of tests first, implement, run the tests, then commit, with bounded retries, a loop guard, and rollback on any failure. It was built through 20+ reviewed pull requests, with full prompt and reply transcripts for debugging and a model benchmarking command. It has built working apps step by step, including an HRMS and a task manager.

SRSCLASSIFICATION

Support Resolution System

Multi-tenant ticket classification backend

An enterprise support system that reads an incoming ticket and routes it to the right queue at 90%+ accuracy, isolated per tenant so one customer's volume can't starve another's.

Classification runs against OpenAI first and falls back to a self-hosted BentoML model when the API is slow, rate-limited or down, so routing degrades instead of stopping. Deployed on Render and Vercel.
